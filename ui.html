Rules — which aircraft alert you

Nothing alerts unless a rule matches it — emergency squawks included. An aircraft must match every condition in a rule, and the first rule that matches wins, so put a narrow exception above the broad rule it carves out of. Registrations and type codes are read from both the database and the live feed, so you can enter any tail number.

Receiver location

Needed by any rule that limits distance or predicts a pass overhead. Leave both blank if no rule uses one.

Notifications

A duration like 30m, 6h or 24h. Counted per rule, so an aircraft that has just alerted under one rule can still alert under another.
